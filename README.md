Expense-Mate is a versatile expense tracking application designed to help users manage their finances efficiently.

## Overview

It features user authentication, expense management (add, edit, delete, view), and a user-friendly dashboard. Built with Flask for the backend, PostgreSQL for data storage, and React.js for the frontend, Expense-Mate ensures a responsive and scalable solution for personal finance management. Docker is used for containerization, facilitating easy deployment and scalability.

## Features

- **User Authentication**: Sign up, log in, and manage user accounts.
- **Expense Management**: Add, edit, delete, and view expenses.
- **Dashboard**: Visualize expenses and manage them through a user-friendly interface.
- **Responsive Design**: Accessible on both desktop and mobile devices.
- **Scalability**: Built with scalability in mind using Docker for containerization.

## Use Cases

1. **Login**: Users can log in to their accounts securely.
2. **Sign Up**: New users can create an account.
3. **Add Expense**: Users can add new expenses with details such as amount, description, and date.
4. **Edit Expense**: Users can modify existing expenses.
5. **Delete Expense**: Users can delete individual expenses.
6. **View Expenses**: Users can view a list of all their expenses.
7. **View Selected Expense**: Users can filter and view specific expenses.
8. **Delete All Expenses**: Users can clear all their expense records.

## Tech Stack

- **Backend**: Flask, SQLAlchemy, Flask-Migrate
- **Database**: PostgreSQL
- **Frontend**: React.js, Axios
- **Containerization**: Docker, Docker Compose
